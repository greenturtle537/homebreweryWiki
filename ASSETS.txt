HomebreweryWiki — required Homebrewery v3.21.0 assets
=====================================================

Source : naturalcrit/homebrewery, tag v3.21.0
Theme  : V3 "5e PHB" (base theme: V3 "Blank")

This is the exact set of url(...) targets emitted by the two theme
stylesheets after Less compilation:

  themes/V3/Blank/style.less
  themes/V3/5ePHB/style.less

Compile and load them in that order: Blank is the base theme, 5ePHB
overrides it. The Less imports assume the repository root is on the
include path (for example: lessc --include-path=. themes/V3/5ePHB/style.less).

Counts
------
125 runtime files, 11,916,709 bytes (~11.4 MiB)
  34 font files
  91 image files

The path list below also names 14 build-input .less files and 3 license
files, so the total number of path lines is larger than 125.

Three additional .ttf fallbacks are referenced by the Font Awesome CSS
but are not present in the upstream tag. The .woff2 files below are the
real sources; the .ttf requests will 404 unless you add them from
another Font Awesome release:

  themes/fonts/iconFonts/fa-brands-400.ttf
  themes/fonts/iconFonts/fa-regular-400.ttf
  themes/fonts/iconFonts/fa-solid-900.ttf

Path handling
-------------
Keep the upstream themes/... layout. The compiled CSS emits:

  /assets/...            -> themes/assets/...
  /fonts/iconFonts/...   -> themes/fonts/iconFonts/...
  ../../../fonts/...     -> themes/fonts/...

Serve these from a configurable base URL, or rewrite the URLs at build
time. Do not assume the wiki is installed at the web root.
